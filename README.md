
# Medicall

AI-powered voice receptionist for healthcare.

Medicall helps patients check doctor availability,
book appointments and cancel appointments through
natural voice conversations.

## Tech Stack

- React + Vite
- Tailwind CSS
- Python + FastAPI
- Pipecat
- ElevenLabs
- Google Gemini
- SQLite

## Project Structure

- frontend/ - Patient interface and admin dashboard
- backend/ - APIs, database and voice agent

## Project Status

Currently under development.
